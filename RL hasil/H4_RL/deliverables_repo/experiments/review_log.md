## 1. Prosedur & Kriteria Anomali

Setiap hari (15.00 WIB pada H4 dan H5), RL mengaudit `experiments/registry.csv` beserta ringkasan run terbaru (`reports/mle/h4_runs_summary.csv`, `reports/mle/h4_module1_tuning.csv`, `experiments/handoff/module1_for_robustness.yaml`, `reports/baselines/`, `reports/module1/`, `reports/synth/`) terhadap lima kriteria wajib:
1. **`git_sha` bersih**: tidak ada run dari *working tree* kotor (`scripts/train.py:git_sha_clean()`).
2. **`split_hash` konsisten**: seluruh run data riil wajib memakai `split_hash = 411aec1a05c90fd698b2aa5aee84a03353e69b1e1d08a088ae78311124bd90ea`.
3. **Kelengkapan 5 seed (`0..4`)**: seluruh model stokastik wajib lengkap 5 seed di setiap origin (`O1, O2, O3`).
4. **Kewajaran MAE vs `seasonal_naive`, `naive_last`, dan level harga (`~Rp50.000/kg`)**: MAE terlalu rendah secara tidak wajar = indikasi bocor; MAE melonjak jauh di atas `naive_last` = indikasi *underfitting*/*overfitting* atau bug skala.
5. **Stabilitas varians antar-seed**: koefisien variasi $\text{CV} = \text{sd}/\text{mean} > 5\%$ ditandai **ANOMALI VARIANS BESAR**.
