\section{Mekanisme \& Konsekuensi Klaim}
\begin{itemize}
  \item \textbf{Mekanisme}: Mempelajari representasi *confounder* laten atau regularisasi invarian lintas lingkungan waktu untuk meningkatkan generalisasi *out-of-distribution* (OOD) pada prediksi lalu lintas.
  \item \textbf{Pembeda terhadap studi kita}: STEVE dan DynaSTar menginferensi *confounder*/lingkungan secara laten pada domain trafik tanpa variabel iklim asal teramati dan tanpa distribusi jeda per edge.
  \item \textbf{Konsekuensi pada Batas Klaim (Brief v2 \S6)}: Regularisasi invarian / *worst-regime penalty* (Modul 4) berstatus \textbf{Stretch} di Sprint 1 dan tidak diklaim sebagai penemuan baru; evaluasi OOD utama kami bertumpu pada stratifikasi rezim iklim fisik teramati (El Ni\~no, kekeringan, hujan ekstrem) dan uji misspesifikasi graph prior (RQ2--RQ3).
\end{itemize}
